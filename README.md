# Meyakhail Interactive Shoe Showcase

Open `index.html` in Chrome, Edge or Firefox. No build step required.

## Features
- Interactive shoe carousel inspired by the supplied video
- Drag/swipe, arrow buttons, and keyboard navigation
- Animated shoe selection and detailed product information
- Color switching, size selection, shopping bag, responsive layout
- Self-contained vector shoe illustrations (no product photos needed)

## Important
This is a working front-end prototype. Shoes are layered SVG illustrations with CSS perspective, not genuine 3D models. To create real freely rotating 3D shoes, source corresponding GLB/GLTF shoe models and replace the renderer with Three.js. The cart is local and does not process orders/payments.
